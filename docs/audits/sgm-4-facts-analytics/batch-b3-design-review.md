自检期间澄清了容易偏离的点：

- 首版一个响应给完整有界结果，不用 Top-N 或跨页可变 snapshot 拼总计；超界整请求失败。
- source/group/model 的高选择性过滤不会减少底层时间范围扫描；仅 token 条件利用现有 token/time 索引。扫描预算按实际索引读取、在 Rust 过滤之前计算。
- 只读连接打开不能复用会创建目录/迁移库的入口；只验证现存路径。共享的是同一个持锁 guard，不是克隆 File 后重新解释锁所有权。
- 原始空模型沿 A 规范为 None，不创建第三种空串身份；字面“未知”模型仍与 None 区分。回执丢失可重放旧 cursor，只有内存游标丢失才从 0 开始。

时间算术在内存脚本中检验 5054 个样本：短窗/完整分钟、跨小时/日、31 天最大跨度、epoch/JSON_SAFE 边缘及 −720..840 偏移，检查区间并集、互斥、自然边界与桶数上界，全部通过。这仅核设计公式，不是 Rust 实现、PBT 或性能证据；实现仍须独立参考模型与回归。
