- 初始化普通用户失败：锁定原生版本User密码上界20，随机密码改为120-bit/20字符；真实初始化及故障注入验证。账号创建丢响应不重复POST，私有pending先落盘，最终配置持久后删除重复pending。
- 新空账本启动退出：补归属NotInitialized是等待collector，不是Storage；仅这个明确枚举作正常暂态，其它存储损坏仍终止监督树，实际空库回归通过。
- 多步组注册被定时发布撤销：沿worker增加私有自动提交协调guard，不放宽fence/lease、不猜主倍率和别名权威；人工暂停/退役仍可撤销。仅register=true要求起步30秒余量，非完成保证。
- 同类竞争影响签发/揭示：保护每个token_step及显式reveal，不包整个64项round，取消仍由原票据结算Uncertain；Catalog与未知写/显式Retry规则不改。锁竞争零发布且Queued不变，真实调用钩子和原取消/后置撤销回归保留。
- 火山添加表单默认type1与已支持后端type8不一致：两类型统一Custom8及完整路径提示，不扩大上游适配范围；新增Node回归经历红→绿。
- 新测试tempdir权限在fermat不同：仅修新空库夹具为显式0700，未放宽生产私有路径规则。
