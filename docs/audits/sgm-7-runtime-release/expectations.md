# SGM7 运行交付事前契约

2026-10-19，基线 ab59a88。独审者先读取架构及已验收契约、未读本批实现，提取下列预期。用户授权一次性完成并在 fermat 实验；不再逐小步重复确认，保留设计/测试/独审。

## 1 契约源

架构 G1–G6/I1–I8、SGM6 C、本地托管预检、B2/B3/O4、SGM5 C、A2/B，以及[运行设计](../../design/source-groups-token-management/subplans/sgm-7-runtime-release.md)。全新安装不授权导入旧数据。

## 2 类型字段

复用 DB v8/wire、各类身份和 revision。仅新增私有启动 RuntimeOptions，沿原 Config 参数。公开根显式配置；配置/报错不泄密，不把本地和原生 ID 混用。

## 3 枚举语义

GLM 95%/临期/pin 不变，火山无临期。暂停、错误耗尽、超限分开；成功 token 流清失败计数但不自动解锁。一个访问 Key 单组/两协议，无新路由算法。

## 4 流程步骤

R1配置；R2私有目录/绑定/单worker；R3监督生命周期；R4 GLM；R5预检/火山/补归属。真实原生初始化→来源/组/禁用成员→核验→原策略/回读→Key→双协议→日志/统计，不造假许可或直接写DB跳过流程。

## 5 行为

一个写者、worker、collector和共享管理预算。只受管Custom type 8，原配置保存与远端成功分开。未知创建不能重复POST。旧CLI保持，新serve不导入keys或启动旧采集/写者。

## 6 时序与恢复

固定任务归属、不积压tick、GLM不饿死火山。真实PID/目录/listener/版本、SQLite启动环境和原生恢复关闭分别核验。停止先广播再join实际工作/usage barrier，再drop库；重开保留操作、映射和窗口。

## 7 不变量

共享来源不重复计量，组内priority独立；暂停不被撤错/重置绕过；失效许可零正向发送；同Key两协议，错组/模型隔离，删除保留历史。两组128-case PBT验证配置与监督所有权；组合测试不以mock管理面代替真实链路。

## 8 性能资源

原1req/s、burst2、64槽/控制优先不变；collector最多4逻辑页、结束后至少10秒；HTTP16连接/4业务槽/单usage。固定端到端清单，保留完整回归与独立性能，无重复编译干扰全量。

## 9 安全副作用

不碰主工作区dirty、本地run、fermat既有服务；验证新目录/端口/服务名无碰撞。管理员/issuer/供应商/访问Key不进日志、URL、仓库或普通报告。只上传白名单源码/假数据，面板回环+SSH。首次引导不在常规运行修改账号/余额/options，不重新setup存量目录。

## 10 跨层退出

真实worker→隔离NewAPI→假上游→双协议→实际日志→账本→页面证据，普通issuer固定身份/共享预算、不回退管理员。至少四类真实编译变异、机械检查及独审五维度通过；部署另核对二进制、PID/listener、环境、重启恢复和保留数据的停止回退。缺真实供应商Key不冒称真实推理已可用。
