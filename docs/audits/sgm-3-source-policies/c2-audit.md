## 实现边界

GLM 组固定/取消固定、火山撤错及上限/重置设置复用原策略 helper，并与实体版本及操作回执同事务提交。局部 Succeeded/0 只表示设置保存；下一次原 C1/O4 刷新才生成目标和许可，原执行器回读确认渠道。旧 GLM 95% 释放、火山双耗尽原因及人工暂停规则不变。

来源模型发现使用原认证和解析，一次显式 GET；同 OperationId 成功重放不重复请求。10秒总超时覆盖正文、1MiB累计大小、1000模型上限、禁止重定向和错误脱敏；取消/失败不留半操作。暂停、退役或模型更新期间的迟到响应不能覆盖新版本。成功复用原 SyncSourceModels 的跨组目标和回读链。

DB v7 只替换 meta 与既有操作表约束，固定父子拓扑重建保留记录；外键始终启用，被重建父子表的额外索引/触发器、外部 FK 依赖及保留名冲突会拒绝迁移并回滚。OperationView wire=2，目录快照 wire=1；无依赖变化、第二个执行器或新增长期表。
