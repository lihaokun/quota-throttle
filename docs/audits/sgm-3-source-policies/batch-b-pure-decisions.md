# SGM-3 B 纯函数审核决策

## R1：投影 PBT 的参考模型不完整

独审发现：原 B3 仅随机结果和分块，借助 `frame(&actual, …)` 从被测状态获取 cursor/period/epoch，没有独立验证这些字段，也缺周期变化和非法批次的随机路径。违反事前 expectations §7 B3，本小步阻断。

处置：参考值独立初始化并维护全部运行字段，不调用生产算法生成期望，也不从 actual 获取版本或游标。增加随机撤错、多日重置、五类非法项，每一步比较完整状态；专门隔离 period 与 epoch 门禁，验证跨周期重放、cutoff 前后和迟到结果。没有删除原有断言或缩小随机空间。独立复审确认充分，关闭 R1。

## C1：退休来源版本输出范围

独审发现：候选和 priority 已排除退休/退役项，但 `source_revisions` 从过滤前映射生成，仍可能包含只剩退休成员的来源，与细化 §5.5 输出排除约定有歧义；未构成渠道启用故障。

处置：保留完整输入身份核验，从保留成员的来源集合筛选版本输出。增加五种来源/成员退休与退役条件的回归，同时断言被过滤项的非法身份仍报错。不为版本元数据新增隐含例外。独立复审确认闭环。

## C2：来源版本额外排序

复审提示：C1 首次修复对版本列表增加了第二次 sort，与“最多一次稳定排序”的字面契约不符。

处置：保留成员来源 ID 构成有界集合，筛选既有 BTreeMap 顺序输出；删除额外排序，不弱化性能约定。最终小范围独立复核确认无遗留问题，关闭 C2。

## 不扩展的范围

不修改 GLM、旧 DDL、运行入口或 NewAPI 管理链；不提前实现 B8–B10、事实账本或 worker 发布。公开 DTO 和 schema 不变。纯函数完成后仍须完成 B 的持久化/重开/迁移验收，才能推进 C。
