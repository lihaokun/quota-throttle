# SGM-3 B 纯函数小步审核

范围：B1–B7 火山状态、投影消费和组内稳定首选。实施基线 `7f4fe7b`，用户确认 B 后按纯函数、存储、组合三步推进。纯函数小步的自动验证、独立复审和五维度自审均通过。本记录不代表整个 B 或 SGM-3 完成；应用库仍为 v3，B8–B10 和持久化 PBT B5 尚未实施。

## 契约与独立审核

依据：[B 细化](../../design/source-groups-token-management/subplans/sgm-3-source-policies-b.md)、[事前 expectations](batch-b-expectations.md)、workflow §5/§6。独立审核者 `sgm3_b_pure_audit` 先读契约，再看基线 diff/新增文件，不以主代理测试结论作为依据。未读取生产材料或运行服务；自动测试由主代理另行执行。

| 契约 | 实现核对 |
| --- | --- |
| B1/B2 固定偏移日边界与初始化 | 默认 01:00 UTC+8；安全整数检查；初始化无观测覆盖，不伪称查到零消费 |
| B3 到期推进 | 常数时间跨多日；旧周期过渡返回调用方；重复 Tick/回拨不重置；暂停不属于此函数写集 |
| B4 投影消费 | 绝对用量、独立 period/epoch、游标与覆盖约束；旧/重复/缺口返回原值；非法批次不发布副本 |
| B5/B6 撤错和改策略 | 撤错只清错误原因；cutoff/epoch 排除旧结果；改规则保留当前用量与已关闭周期边界 |
| B7 稳定首选 | 完整身份核验先于过滤；当前可用保持；失效后稳定轮转；跨组共享来源不复制计数 |
| 接口/副作用 | 证据不能从前端 JSON 反序列化；无 I/O、时钟读取、迁移、worker/CLI/面板接线 |

首审发现 B3 的参考模型不完整（阻断）和退休来源版本输出歧义（非阻断），均修复并补回归。复审关闭阻断，另提示版本排序次数的字面契约差异，已复用有序来源映射消除。最终小范围复核确认无遗留问题。处置见[决策记录](batch-b-pure-decisions.md)。

## 自动验证

机械入口：`bash scripts/contract_audit/sgm3_b_pure.sh`。核对生产改动白名单、B1–B7 标记、纯函数无 I/O、共享枚举不重复定义、格式及模块测试。`VolcanoPolicy::validate` 只提取既有配置校验，合法范围不变；公开 wire、旧 DDL、GLM 算法和运行入口均未改。

新增 14 项测试，包括 4 项 PBT，每项 128 cases：

- B1：独立原因/计数模型，随机暂停、成功/失败/忽略、上限/阈值编辑、撤错和重置。
- B2：独立枚举 UTC 日期边界，覆盖合法分钟/固定偏移、多日跳跃、回拨、编辑与幂等。
- B3：独立构造并维护完整运行状态；随机分块、撤错、多日重置和五类非法项，逐步比较游标、周期、epoch、覆盖及全部计数/原因；包括同 epoch 错 period、重放、缺口和迟到结果。
- B4：两个独立索引环，对拍共享源暂停/错误、配置/运行版本、单组成员移除、无候选和恢复不抢占。

确定性测试另覆盖 0/1024/1025 项、空投影、JSON_SAFE 溢出、cutoff 同秒、双原因、成功不解锁错误、未知来源不抢占、身份错误先于过滤、五种退休/退役过滤以及最大目录规模。最终机械门禁通过，14 项模块测试通过。`cargo clippy --locked --offline -j 2 --all-targets` 通过，仅有原来的 6 条警告；`cargo build --release --locked --offline -j 2` 通过。

最终 `cargo test --locked --offline -j 2 --quiet -- --test-threads=4`：**302 passed、0 failed、1 ignored**，285.18 秒。全量测试中的假 HTTP 使用获准的随机回环监听，数据库均为隔离测试材料；不使用生产端口或 key。既有 ignored 原生 NewAPI 集成未在本轮启动，本轮纯模块不修改远端执行链。

## 定向变异验证

源码副本 `/tmp/quota-throttle-sgm3-b-pure-mutations.bf2CVc` 与其 `target/` 均独立于开发分支，冷构建后先跑通 14 项模块测试。逐项注入、执行指定测试、恢复，每项均为 exit 101 且出现 `test result: FAILED` 和断言失败，不以编译失败充数。恢复后生产模块及测试逐文件比对无差异，重新编译后 14 项再次全部通过。变异种子仅留临时副本，不回写分支。

| 变异 | 捕获证据 |
| --- | --- |
| M1 状态派生忽略 manual_paused | B1：Available 不等于 Paused |
| M2 clear_error 清 token/上限原因 | B1：预期用量 1，实际归零 |
| M3 不检查 error_epoch | cutoff/epoch 确定性测试：旧批次 Applied，不是 Stale |
| M4 绕过 Duplicate/Gap 游标门禁，再次消费重复批次 | B3：重放返回 Applied，不是 Duplicate |
| M5 修改重置时刻时清用量 | B2：预期 (70,40,true)，实际 (0,0,false) |
| M6 不保留仍可用的 preferred | B4：选错成员，独立环模型不允许抢占 |
| M7 不检查 period_id，只检查 epoch | B3：同 epoch 错 period 被 Applied |
| M8 不保存接受的 evidence_cursor | B3：完整状态对拍发现 None 不等于 Some(1) |

M7/M8 特别检验独审 R1 修复后的参考模型。缺行自动补零和迁移私有材料篡改两项属于尚未实施的存储阶段，不计本小步变异通过。

## 五维度自审与交付边界

- 一致性：纯函数范围与 B1–B7 对齐；来源运行状态由 SourceId 唯一标识，组状态只保存本组首选/游标。没有逐 key 上游绑定或火山临期。
- 风格：复用既有 ID、SourceKind、MembershipLifecycle、PolicyError 与配置校验，不新增依赖或公开管理错误码。
- 正确性：两个耗尽原因独立，暂停优先；副本计算失败不发布；数字/批次/来源容量均有界。独审测试缺口修复，不降低期待。
- 性能：跨多日常数次算术；选择只作一次显式稳定排序，来源版本复用有序映射；最大规模测试设 5 秒宽松预算。没有后台任务或新增轮询。
- 可维护性：生产代码集中于 volcano 纯模块，目录仅提取原配置校验；没有重复统计账本、网络客户端或状态存储层。
